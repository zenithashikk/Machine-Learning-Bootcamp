# Class-06: Pandas for Data Manipulation

## Overview
This class focuses on Pandas, one of the most important Python libraries for data manipulation and analysis. Learned how to work with structured datasets, clean data, perform filtering, and analyze information efficiently.

## Discussed Topics

- Series and DataFrame
- Reading and Writing Data (CSV, Excel, JSON)
- Data Selection and Filtering
- Handling Missing Values
- Data Aggregation and GroupBy
- Merging and Joining Datasets
- Basic Time Series Operations

## Learning Outcomes

- Understand Pandas Series and DataFrames.
- Read and write different data file formats.
- Select, filter, and manipulate datasets.
- Handle missing values.
- Perform grouping and aggregation.
- Merge and join multiple datasets.
- Work with basic time series data.

## Technologies & Libraries

- Python
- Pandas
- Jupyter Notebook / Google Colab
